# mcp-for-i-skills

Shared skills for `mcp-for-i` agents.

## Contents
- `ibmi-mcp-operations/` IBM i operational workflow skill pack.
- `ibmi-mcp-universal/` Agent-agnostic IBM i playbooks for full `mcp-for-i` tool navigation (session, QSYS, IFS, SQL/CL, ops control, audit/journaling, cleanup).

## Versioning
This repo is versioned with git tags/releases. The control-plane can update skills from a selected branch.
